## What I'm running right now

**[RantAIClaw](https://github.com/RantAI-dev/RantAIClaw)**, a Rust runtime for AI employees. I build these parts of it:

- `channels`: the agent lives in Telegram, Discord, Slack, WhatsApp and Lark. In group chats it only talks when someone mentions it.
- `memory`: every conversation keeps its own notes, so group guests can't read the owner's diary.
- `skills`: install, update and remove ClawHub skills from the CLI, TUI or web. A tampered download fails the SHA-256 check and never loads.
- `scheduler`: jobs you can pause, edit and rerun, or just ask for one in chat.

## Before that

**[RantAI Agents](https://github.com/RantAI-dev/RantAI-Agents)**, an agent platform in TypeScript:

- a visual workflow builder with 28 node types, so teams automate AI work without code
- 12 chat artifact types (PDF, PPTX, XLSX, notebooks, React apps), with validators that reject broken LLM output
